## Visual Description
- Shape: circle
- Size: ~100–120px diameter — large enough to read at a glance
- Background: yellow (# NEEDS CONFIRMATION)
- Border: none
- Border radius: 50%
- Shadow: none observed
- Typography: large bold number (~28–32px, black), small descriptor text below (~11–12px, black)

## States
- Default: yellow fill, black text
- Hover: n/a (static element)
- Active: n/a

## Usage Notes
- Positioned overlapping the top-right corner of the hero image — bridges the text zone and image zone visually
- Contains one stat: number of clients helped, reviews, money saved, etc.
- Number is the dominant element — descriptor text is secondary and brief (max ~5 words)
- Do not use more than one stat badge per hero section
- Works with circle shape; can also be rounded rectangle — maintain the overlap positioning either way
