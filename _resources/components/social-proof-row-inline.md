## Visual Description
- Shape: horizontal strip, full width of its container column
- Size: ~60–72px tall
- Background: light (white or very light gray) — NOT dark like the bottom bar variant
- Border: subtle top border or none
- Border radius: ~12–16px (matches the card above it, or slightly rounded)
- Typography: ~12–13px count text, gold stars

## Layout
- Left: overlapping circular avatar photos (3–5)
- Center/right: star rating row + count text below stars
- All elements horizontally aligned in a single row
- Sits directly below the gradient card as its own distinct strip

## States
- Default: static display element

## Usage Notes
- This is the INLINE variant of social proof — it sits in the content column below the hero card, not inside a dark bar
- Contrast with bottom-bar-results-social-proof: that one is dark, floats below image, and combines outcomes + social proof; this one is light, column-width, and is social proof only
- Contrast with avatar-stack-star-rating: that's just the cluster element; this is the full strip/container
- Light background makes it readable against the dark page background that surrounds it
- Works best in bento-split or text-above-image layouts where there's a column below the main card
