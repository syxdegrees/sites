## Visual Description
- Shape: row of overlapping circular avatar images + star row + count text
- Avatar size: ~32–40px diameter each, overlapping by ~30–40%
- Avatar count: 3–5 circles
- Stars: 5 gold stars, ~14–16px each
- Count text: ~12–13px, white or dark depending on background

## Layout
- Avatars sit left, stars sit above or beside count text
- Stars + count stack vertically: stars on top, count text below
- Entire cluster sits to the right of the outcome items in the bottom bar

## States
- Default: static display
- Hover: n/a

## Usage Notes
- Avatars should be real client photos when available — stock faces are obvious and reduce trust
- Always show 5 stars — this is a display component, not a live rating widget
- Count text should be specific and impressive: "Over 1,600 yards transformed" beats "500+ clients"
- Use inside bottom-bar-results-social-proof or as standalone social proof element below hero CTA
- Works on both dark and light backgrounds — adjust text color accordingly
