## Visual Description
- Shape: row of individual pill chips, each fully rounded
- Size per chip: ~auto width based on text, ~28–32px tall
- Background per chip: light (white or very light tint with slight border)
- Border: subtle light border or none
- Border radius: 9999px per chip
- Shadow: none observed
- Typography: ~12–13px, dark text, medium weight; checkmark (✓) prefix

## States
- Default: light pill chips, dark text
- Hover: n/a (static element)
- Active: n/a

## Usage Notes
- Sits below the CTA button in the text block zone — not anchored to an image
- Each chip is independent — 3 chips is standard but can vary
- Checkmark prefix reinforces positive outcomes
- Items should be client outcomes, not features (same rule as results-bar-dark)
- This variant suits layouts where the hero image is separate from the text column (split layouts)
- Contrast with results-bar-dark: that component is dark and anchored to the image bottom; this is light and floats in the text zone
