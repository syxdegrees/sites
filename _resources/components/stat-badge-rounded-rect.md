## Visual Description
- Shape: tall rounded rectangle / pill (portrait orientation, wider than circle variant)
- Size: ~120px wide × ~160px tall approximately
- Background: solid color fill (deep plum in Big Little Voices example)
- Border: none
- Border radius: ~20–24px or 50% on short axis (very rounded)
- Shadow: none observed
- Typography: large bold number (~32–40px, gold/accent color), smaller label below (~12–13px, white)

## States
- Default: solid color fill, accent-colored number, white label
- Hover: n/a (static element)
- Active: n/a

## Usage Notes
- Used as the third visual element in the dual-image right column — occupies the bottom-right slot
- Taller portrait orientation distinguishes it from the circle stat badge variant
- Number uses the brand accent color (gold, yellow) — not white — for emphasis
- Label is white, 2–4 words
- Choose this variant when the layout has a right-side image column; circle badge better suits overlapping a single wide hero image
