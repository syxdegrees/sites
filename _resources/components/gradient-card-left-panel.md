## Visual Description
- Shape: rounded rectangle card; contained within the left column with visible gap from column edges
- Size: fills ~left half of viewport, with internal padding ~32–40px
- Background: brand gradient (e.g. orange → purple/magenta diagonal)
- Border: none
- Border radius: ~16–20px
- Shadow: subtle or none — dark page background provides natural contrast

## Layout
- Contains: large impact headline (all-caps or heavy weight), subheadline with selective bold, CTA button
- All content left-aligned within the card
- Card does NOT extend full column height — it stops above the social proof row below

## Usage Notes
- This is the defining element of the bento-split layout — the gradient replaces a hero image on the left
- Works for high-energy brands: fitness, coaching, performance services
- Headline should be short, punchy, all-caps or heavy weight — emotional impact over description
- Gradient direction should complement the brand — diagonal (top-left to bottom-right) is most common
- The card being a contained box (not full-bleed) is intentional — it creates visual breathing room
