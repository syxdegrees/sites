## Visual Description
- Shape: wide rounded pill or rectangle, floating below or slightly overlapping the hero image bottom edge
- Size: full-width of hero content area, ~60–72px tall
- Background: dark solid color (forest green, near-black, or brand dark)
- Border: none
- Border radius: ~16–24px (heavily rounded, not flush like results-bar-dark)
- Shadow: subtle drop shadow to lift it off the image

## Layout
- Left half: 3 checkmark outcome items with icon, evenly spaced
- Right half: avatar stack + star rating + count text, right-aligned or centered in right zone
- Divider: subtle vertical separator or just whitespace between left and right halves

## States
- Default: static display element
- Hover: n/a

## Usage Notes
- Distinct from results-bar-dark: that component is flush to the image bottom edge with no border radius; this floats as a separate pill below the image
- Combines TWO social proof types in one bar: outcomes (left) + credibility (right)
- Checkmark icons use brand accent color (gold, yellow) — not plain text checkmarks
- Avatar stack shows 3–5 overlapping real client photos — adds human element
- Star rating is always 5 stars for display purposes
- Count text is specific: "Over 1,600 yards transformed" not generic "Happy Clients"
