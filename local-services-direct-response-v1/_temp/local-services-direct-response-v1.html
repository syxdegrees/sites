Notes — Hero

2

Hero — formatted as a landing page Full-bleed section, contained inner grid, ~70–85vh. Journey beat: Ordinary World + Call to Adventure.
Slots, in order: eyebrow — one line naming the ideal-client avatar (e.g. "For overworked teachers", "Houston homeowners") so the visitor knows the page is for them · headline (1–2 lines, promises the desired outcome / the problem solved — not a description of the service) · subhead (how you deliver on it; call out location if local) · two CTAs side by side — primary solid, secondary outline/ghost; primary is specific about what happens next · social-proof row directly beneath the CTAs: 5-star graphic + rating / "trusted by N" line, optional 3–5 small logo slots.
Visual area sits right of the copy on desktop (show the after-state / happy customer, never the work being done); stacks below copy on mobile with the primary CTA above the fold. This section must stand alone as a conversion unit even with nothing below it.

Notes — The Plan

7

The Plan Contained-wide. Journey beat: the map forward — makes the path feel simple and low-effort. People are terrified of complexity.
Slots: centered heading · exactly 3 steps — not 4, not 5 — each = step number + label ("Step 1 / Step 2 / Step 3", never bare "1 / 2 / 3") + icon slot + step-title slot + one supporting line.
Step 1 = the client takes action — repeat the hero CTA verb. Step 2 = your whole process, simplified to its essence (you take the messy middle out of their hands). Step 3 = their happy outcome.
Row on desktop; on mobile switch to a vertical timeline (horizontal never works on a phone). Optional arrows / connecting timeline to make it feel like a journey, not a list. Optional low-commitment CTA centered beneath.

Page type: About  ·  Role: part of the Control template
Model: Modified sales page for the brand — a Hero's-Journey / StoryBrand arc told from the company's origin, every beat bent back to "…and that's why we're the right choice for you." Incorporates the Leader / Intro / Body credibility spine from skill-site-content-about.

Sections: 12  ·  Body copy target: 800–1,200 words, H2/H3 structure.
Notes on this page carry content intent as well as structure (it is copy-led). Colors, type, and final copy still come from the brand style guide + content brief.

About-page conventions
inline call = a click-to-call phone link woven into paragraph text (better than a button inside prose). Uses CallRail dynamic number insertion — see instructions.md "Phone numbers".
anchor text literal = the exact, keyword-optimized words a body link should use, matching its destination. Where the destination page doesn't exist yet it is written as plain text now and listed in the table below as a page to create.
Primary CTA (button) appears at the Leader, mid-page (Who We're For), and the closing band. No link stuffing — each internal link on this page is unique.
